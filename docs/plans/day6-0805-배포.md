## 사전 준비 — 앱 컨테이너화

로컬에서는 앱을 IDE로 띄웠지만, 서버에서는 컨테이너로 돌린다.

1. `Dockerfile` 작성 (멀티스테이지: gradle 빌드 → JRE 실행 이미지)
2. `docker-compose.yml`에 `app` 서비스 추가
   - `JAVA_TOOL_OPTIONS=-Xmx384m` ← 메모리 상한 (아래 참고)
   - DB 호스트는 `localhost`가 아니라 **서비스명**(`postgres`, `mongo`, `redis`)
   - `depends_on` + healthcheck 조건
3. **로컬에서 먼저 `docker compose up`으로 앱까지 띄워본다.** 서버에서 처음 시도하면 디버깅이 훨씬 어렵다.

## 배포 절차 8단계

| # | 할 일 | 비고 |
|---|---|---|
| 1 | EC2 인스턴스 생성 (Amazon Linux 2023, t3.micro) | 프리티어 해당 여부를 **본인 계정에서 직접 확인** |
| 2 | **Budget Alert 설정** | 인스턴스 만든 직후 즉시. 미루면 잊는다 |
| 3 | Docker 설치 | `sudo dnf install -y docker` → `sudo systemctl enable --now docker` |
| 4 | 저장소 clone | public이므로 인증 불필요 |
| 5 | `.env` 작성 | **로컬과 다른 비밀번호를 쓴다** |
| 6 | `docker compose up -d` | `docker ps`로 컨테이너 4개 확인 |
| 7 | 보안그룹 인바운드 8080 허용 | **22(SSH)는 내 IP로만** 제한 |
| 8 | 브라우저 접속 확인 → README에 URL 기재 | 최종 산출물 |

## ⚠️ 거의 확실히 만나는 문제 — 메모리 부족

t3.micro의 RAM은 **1GB**인데 컨테이너 4개를 올린다:

| 컨테이너 | 메모리 |
|---|---|
| Spring Boot (JVM) | 400~600MB |
| PostgreSQL | 150~250MB |
| MongoDB | 250MB+ |
| Redis | 30~80MB |
| **합계** | **1GB 초과 → 컨테이너가 조용히 죽는다** |

증상이 고약하다: **애플리케이션 로그에 예외가 안 남는다.** 프로세스가 밖에서 강제 종료되기 때문이다.

**진단**: `dmesg | grep -i "killed process"` → OOM Killer 기록 확인

**대응 (전부 무료)**:
1. **swap 2GB 추가** ← 가장 효과적
   ```bash
   sudo dd if=/dev/zero of=/swapfile bs=1M count=2048
   sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
   ```
2. JVM 힙 상한 `-Xmx384m`
3. MongoDB `--wiredTigerCacheSizeGB 0.25` (compose에 이미 있음)
4. Redis `--maxmemory 64mb` (compose에 이미 있음)
5. 그래도 안 되면 **Redis를 빼고 로컬 캐시로 후퇴** — URL 확보가 우선

> 💡 **이게 오늘 가장 값진 산출물일 수 있다.** 로컬에서는 절대 만날 수 없는 문제이고,
> 자격요건 3이 존재하는 이유가 바로 이것이다. 반드시 트러블슈팅 로그로 기록한다.

## 의도적으로 하지 않는 것 (README에 명시)

| 항목 | 이유 |
|---|---|
| HTTPS / 도메인 | 도메인 구입 + 인증서 + 리버스 프록시 = 반나절 이상. `http://IP:8080`으로 요건은 충족된다 |
| RDS / DocumentDB 분리 | 비용 + 설정 시간. 단일 인스턴스 compose로 통일 |
| CI/CD 자동 배포 | 지원 후 과제. 오늘은 **수동 배포로 URL 확보**가 목표 |
| 무중단 배포 | 범위 외 |

## 🚨 손절 기준

- **배포가 하루를 넘기면** RDS·DocumentDB 없이 EC2 단일 인스턴스 compose로 단순화한다.
- 그래도 안 되면 **Redis 제외 → MongoDB 제외(PostgreSQL만)** 순서로 줄인다.
  **접속되는 URL 하나가 완벽한 아키텍처보다 100배 중요하다.**

## 서류 심사 기간 동안 인스턴스를 켜 둔다

채용담당자가 URL을 열었을 때 죽어 있으면 배포하지 않은 것과 같다.
프리티어 750시간/월 = 1대 24시간 가동. 제출 후 최소 2~3주는 유지한다.
