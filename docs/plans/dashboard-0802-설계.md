## 데이터 흐름

```
로드 → GET /api/contents (공개)
     → 콘텐츠별 GET /api/contents/{id}/highlights 병렬 프로브 (Promise.allSettled)
     → 결과 비어있지 않은 콘텐츠만 드롭다운에 (기본 선택: 첫 항목)
선택 → GET /timeline + /highlights → SVG 차트·표 렌더 + 응답시간 배지 갱신
```

- 프로브 근거: "집계된 콘텐츠 목록" API가 없고 코드 프리즈로 추가 불가 →
  클라이언트 프로브가 유일한 방법. highlights는 인덱스드 PostgreSQL 마트 조회(실측 ~0.5ms)라
  193요청 burst 부하 미미, 브라우저 동시 연결 제한이 자연 스로틀.
- **한계 기록**: 코드 프리즈 해제 후 "집계된 콘텐츠 목록" 엔드포인트 추가가 올바른 해법.
