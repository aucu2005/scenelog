# 골든셋 다양화 — 하이라이트 검출 정밀도·재현율 측정 설계

> 작성: 2026-08-07 · 상태: 구현 완료 (2026-08-07)

## 1. 배경과 목적

하이라이트 검출(ZSCORE_V1)의 기존 정확도 근거는 기본 각본(27%·68% 지점 피크 2개) 1건의
정답지 채점 — **2/2 = 100%** 이다. 정답 피크 수가 2개뿐이고 각본 구조가 한 가지라서:

- **허위 검출(false positive)을 잴 수 없다** — 피크 없는 콘텐츠를 검사한 적이 없다.
- **약한 신호·가장자리·인접 피크** 같은 어려운 상황에서의 성능을 모른다.
- 임계값 z ≥ 2.0은 통계 관례(2σ ≈ 상위 2.3%)에 근거한 시작값이며, 실측 근거가 없다
  (HighlightDetector 주석에 "시작값" 명시, EDA 노트는 일정 손절로 드롭됨).

이 작업은 골든셋을 **구조 12종 × 시드 10개 = 120회 실행(정답 피크 170개)** 으로
다양화하여 검출기의 **정밀도(precision)와 재현율(recall)** 을 측정하고 기록한다.

## 2. 범위

**포함**
- 순수 JUnit 평가 하네스 1개: `src/test/java/com/scenelog/analytics/GoldenSetEvalTest.java`
- 실행 경로는 운영과 동일한 클래스: `ReactionSimulator` → `Aggregator` → `HighlightDetector`
- 측정 결과의 dev-log 기록

**제외 (오늘 하지 않는 것)**
- **운영 코드 수정 0줄** — 검출기·시뮬레이터·집계기를 일절 고치지 않는다.
- 임계값 조정 — 나쁜 숫자가 나와도 z=2.0을 유지하고 한계로 기록한다 (측정이 튜닝이 되면 안 된다).
- 임계값 스윕(1.5/2.0/2.5 비교) — `Z_THRESHOLD`가 상수라 운영 코드 변경이 필요. 후속 작업으로 남긴다.
- EC2 접근 — 서버 동결 유지. 이 측정은 전부 로컬 메모리 연산이다.

## 4. 채점 규칙

한 실행에서 검출 구간 목록 D와 정답 피크 목록 A를 대조한다. **1초라도 겹치면 매칭**이다.

- 정밀도 관점: d ∈ D가 A의 어떤 피크와도 겹치지 않으면 **FP**, 하나 이상과 겹치면 **TP(검출)**.
- 재현율 관점: a ∈ A와 겹치는 검출이 하나도 없으면 **FN**, 있으면 **발견**.
- 120회 전체를 합산하는 **마이크로 평균**:
  - 정밀도 = TP(검출) / (TP(검출) + FP)
  - 재현율 = 발견 / 전체 정답 피크 수

비대칭 주의: 인접 피크 2개가 하나의 검출 구간으로 병합되면 정밀도 쪽은 TP 1, 재현율 쪽은 발견 2로
센다. 이 규칙은 병합을 벌점 없이 수용한다 — 사용자 입장에서 "그 구간이 하이라이트"라는 답은 맞기 때문.
규칙 자체를 코드 주석과 dev-log에 명시한다.

## 5. 구현 형태

- 새 파일 1개 `GoldenSetEvalTest.java`. 구조 정의(record) + 채점 함수 + 시나리오 목록.
- 각 실행: `generate(구조, 20명, 시드)` → `aggregate(events, 10)` → `detect(totals, 10)` → 채점.
- 출력: 구조별 집계표(발견/정답, FP 수)를 콘솔에 출력하고, 마지막에 정밀도·재현율 합산.
- **측정값 고정(assert)**: 첫 실측 후 합산 TP/FP/FN 수치를 assert로 고정한다.
  이후 검출기 상수를 바꾸면 이 테스트가 깨진다 — 평가가 곧 회귀 방지가 된다.
- 채점 함수(겹침 판정)는 자체 단위 테스트 3~4개를 같은 파일 안에 둔다 (채점기가 틀리면 전부 무효).

## 6. 성공 기준·기록 원칙

- `gradlew test` 전체 green (기존 34개 + 신규).
- 측정 숫자는 **나온 그대로** dev-log에 기록한다. 구조 4·5·12(약한·가장자리·완만 피크)는
  놓치라고 설계한 스트레스 케이스로, 재현율 100%가 나오지 않는 것이 정상 범위다.
- 기록 항목: 구조별 결과표, 합산 정밀도·재현율, 발견된 검출기의 성질(병합 동작, σ 부풀림 등).

## 7. 후속 (범위 외, 기록만)
